# Keyboard shortcuts of the Git plugin

| Command | Keys |
| --- | --- |
| Commit... | <Keys>Ctrl+Alt+K</Keys> |
| Push... | <Keys>Ctrl+Alt+Shift+K</Keys> |
| Pull... | <Keys>Ctrl+T</Keys> |
| Fetch, New Branch..., Branches..., Show History, Show File History, Show Diff | |
| Roll Back..., Add to .gitignore, Stash Changes..., Unstash Changes..., Initialize Repository | |

In the **Commit** window's message box, <Keys>Ctrl+Enter</Keys> commits and <Keys>Ctrl+Shift+Enter</Keys> commits and pushes.
